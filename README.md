# ESP32-PPG-Mnoitor

Development of an ESP32-based heart rate monitoring system using optical sensing, real-time data acquisition, and MATLAB signal visualization.

Introduction - Photoplethysmography (PPG) is a noninvasive optical technique used to monitor changes in blood volume within peripheral tissue. The technique is reliant between the light and biological tissue, in which light is absorbed and reflected back into a sensor. During the cardiac cycle, the heart contracts and relaxes resulting in various amounts of light absorbed and reflected by the tissue. These variations can be detected using a photosensor and analyzed to determine heart rate. 

The objective of this project is to develop a wearable heart rate monitoring system using an ESP32 microcontroller, light emitting diodes (LEDs), and the photosensor configured in a reflective arrangement. The LED illuminates the fingertip, while the photosensor measures variations in reflected light intensity. The sensor output is acquired by the ESP32 and recorded for signal processing and analysis. This project demonstrates optical sensing by microcontroller data acquisition, and signal processing in biomedical instrumentation.
